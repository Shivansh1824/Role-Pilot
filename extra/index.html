3. Turn-Taking Protocols & Anti-Hallucination

Four engineering guardrails that guarantee realistic turn-taking and stop AI hallucinations:

1. Single Microphone Token

Only ONE panelist holds the mic per turn. Max 1 focused question per turn. Never stack questions. Keep turns to 1–3 spoken sentences for natural voice conversation.

2. Speaker Tagging Protocol

Every response must declare the speaker tag: [Alex (Tech Lead)], [Maya (Product Manager)], or [David (Hiring Manager)]. Hand-offs use explicit tags.

3. Resume Fact-Sheet Grounding

Inject candidate's verified stack, past companies, and projects into system prompt. Strict rule: Never invent fictional companies or tools the candidate did not list.

4. Anti-Bluffing Probes

If candidate gives vague buzzwords ("just microservices"), immediately probe: "Specifically, what partition key and cache eviction policy did you configure?"

4. Dynamic 3-Tier Difficulty Ladder

Tier Level Target Depth Focus Concepts Escalation Criteria
Tier 1: Foundational Junior / Mid Standard API design, basic CRUD, schema design, basic indexes. Candidate explains basic trade-offs with zero hesitation.
Tier 2: Mid-Senior Senior Concurrency, race conditions, caching eviction, rate limiting, customer latency. Candidate mentions distributed locks, idempotency, circuit breakers.
Tier 3: Staff / Lead Principal / Lead Split-brain partitions, cascading failures, read-your-writes replication lag. Candidate exhibits deep mastery of Tier 2 edge cases.
