The True Multi-Voice Architecture

How we achieve a perfectly synchronized, 3-person AI interview panel with zero overlapping voices and a unified memory.

❌ The Problem with Default AI Agents

If you put 3 independent AI agents in a room, they act like 3 people wearing noise-canceling headphones. They don't share memories, they waste tokens by thinking separately, and when the candidate speaks, they all try to answer at the exact same time.

✅ Our Solution: The "Puppeteer" Architecture

Instead of 3 separate brains, we use One Central Brain (Gemini) controlling 3 "Dumb" Voice Bodies (Agora). Here is how it flows in real-time:

1. The Ears & Mouth (Agora Cloud)

The candidate speaks. Agora instantly translates the audio to text (STT). Because there are 3 agents in the room, Agora sends 3 identical text transcripts to our server at the exact same millisecond.

2. The Barrier (Next.js LLM Router)

Our Custom LLM API Route acts as a traffic controller. It receives all 3 requests but intentionally "holds" them. Using a lightning-fast In-Memory Global Map, it deduplicates the requests so we don't process the same sentence three times.

3. The Brain (Gemini Flash)

Our server makes one single, highly efficient call to Gemini. Gemini reads the transcript, applies our Prompt Engineering rules (like the Hit Counter and Verbal Handoffs), and decides who should speak next (e.g. Maya).

4. The Puppet Strings (Audio Routing)

Our server now has 3 HTTP connections waiting for an answer. It sends the AI text exclusively down Maya's connection. It explicitly returns a blank/silent response to David and Alex's connections. Result? Maya speaks, and the other two stay perfectly quiet.
